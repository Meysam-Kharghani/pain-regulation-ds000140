# Down-regulation attenuation robustness outputs

This directory contains canonical down-minus-passive ROI and signature summaries used to evaluate sign and FDR stability across the main and motion-sensitivity analysis sets.

Files:

- `canonical_down_minus_passive_roi_results.tsv` — all canonical ROI rows for down-minus-passive.
- `canonical_down_minus_passive_signature_results.tsv` — all canonical signature rows for down-minus-passive.
- `selected_down_minus_passive_roi_results.tsv` — prespecified sensory-region subset used in the main summary.
- `selected_down_minus_passive_signature_results.tsv` — selected signature subset used in the main summary.
- `canonical_down_minus_passive_sign_stability_summary.tsv` — sign and FDR stability across the main, FD-bad-run-exclusion and high-motion-subject-exclusion sets.

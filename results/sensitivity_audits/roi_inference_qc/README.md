# ROI inference and quality-control tables

## Inputs

- ROI statistics: `results/roi_signatures/roi_stats.tsv`
- Behavioral trial table: `results/behavior/behavior_trials_master_clean.tsv.gz`
- Run-level quality-control table: `results/preprocessing_qc/analysis_inclusion_table.tsv`

## Interpretation

Family-level and all-ROI corrected P values should be reported together. The
inferential hierarchy distinguishes within-dataset robustness from independent
replication and separates primary results from sensitivity and exploratory
analyses.

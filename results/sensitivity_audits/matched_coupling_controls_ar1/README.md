# Matched coupling controls after AR(1) prewhitening

These tables repeat the standardized selected-pathway analysis using the
AR(1)-prewhitened trialwise ROI estimates. The same forward, reverse,
synchronous, and time-reversed definitions are used, together with 5,000
shared-source permutations, 5,000 nonzero circular shifts, and 5,000
participant bootstrap resamples.

The forward composite remained associated with up-regulation success
(`r = -0.58484`, `p = 0.000351`). The prewhitened and primary forward scores
were strongly correlated (`r = 0.96307`). The null models and direct
forward-minus-control comparisons are conditional on the selected pathway and
do not repeat the screening family.

The participant-level forward association is provided as both PNG and SVG in `figure4_forward_participant_scatter.*`.

A reference-score correspondence threshold of `r = 0.95` is used for this sensitivity rerun; the observed correspondence was `r = 0.96307`.

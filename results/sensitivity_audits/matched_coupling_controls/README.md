# Matched coupling controls

These tables contain the rating-adjusted selected coupling result and its matched controls.

- `reported_coupling_summary.tsv`: forward, reverse, synchronous, time-reversed, bootstrap-difference, and null-model summaries.
- `shared_source_permutation_null.tsv`: 5,000 conditional within-run shared-source permutations.
- `circular_shift_null.tsv`: 5,000 conditional nonzero within-run circular shifts.
- `coupling_dcm_summary.tsv`: concise coupling and run-separated DCM results.

The forward association is exploratory and post-selection. The null models are conditional on the selected pathway and do not repeat pathway screening.

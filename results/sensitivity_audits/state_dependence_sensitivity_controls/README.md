# State-dependence sensitivity controls

## Inputs

- Regulation-trial state table: `results/behavior/trialwise_behavior_latents.tsv`
- Behavioral trial table: `results/behavior/behavior_trials_master_clean.tsv.gz`

## Scope

The analyses evaluate alternative scales, bounded-outcome transformations,
available response range, cross-fitted passive baselines, and stratification by
stimulus intensity and expected pain. They are sensitivity analyses for the
state-dependence result and do not establish a mechanistic interaction.

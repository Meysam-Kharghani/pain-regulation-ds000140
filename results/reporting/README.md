# Reporting assets

This directory contains the exact figures and machine-readable values used for the reported results.

- `figures/`: four primary and six supplementary figures as 300-dpi PNG and vector PDF.
- `figure_data/`: plotted values and null distributions.
- `table_data/`: exact primary and supplementary tables.
- `source_data_map.tsv`: mapping from each displayed item to its source TSV.

The source-data files are authoritative for reported numerical values. Earlier screening and diagnostic outputs elsewhere in the repository are retained for provenance.

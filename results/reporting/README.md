# Reporting assets

This directory contains the exact figures and machine-readable values used for the reported results.

- `figures/`: four primary and six supplementary figures as 300-dpi PNG files.
- `figure_data/`: plotted values and null distributions.
- `table_data/`: exact primary and supplementary tables.
- `source_data_map.tsv`: mapping from each displayed item to its source data.
- `supplementary_data_s1.xlsx`: journal-ready full 256-test run-position-matched ROI sensitivity table; the authoritative machine-readable source remains `results/sensitivity_audits/neural_matched_passive_roi/neural_matched_passive_summary.tsv`.

The source-data files are authoritative for reported numerical values. Earlier screening and diagnostic outputs elsewhere in the repository are retained for provenance.

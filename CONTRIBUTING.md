# Contributing

This repository accompanies a specific scientific reanalysis. Corrections that improve reproducibility, documentation or code reliability are welcome.

Before opening a pull request:

1. open an issue describing the proposed change;
2. keep scientific-result changes separate from documentation-only changes;
3. do not add raw participant data, restricted signature maps, licensed atlas files or large neuroimaging derivatives;
4. run `make validate`;
5. describe whether the change affects any reported result.

Questions about the original dataset should be directed to the dataset's maintainers. Questions about this reanalysis may be opened as repository issues.
